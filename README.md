# Running on Treadmill Analysis

瀏覽器端單鏡頭 2D 跑步機步態分析工具。使用 BlazePose GHUM Heavy、時間平滑及實際影片顯示區域對齊，讓直式跑步影片的骨架覆疊更穩定。重播、拖曳或逐格檢查時，右側步頻、踝軌跡、質心代理軌跡與左右髖膝角度都會依影片時間同步更新。

## 新增分析

- 肚臍附近 Center of Mass 代理點、影像軌跡與垂直晃動圖。
- 左右踝路徑長度、垂直振幅，以及左右髖膝每一步活動範圍與不對稱提示。
- 固定軀幹與固定髖點的關節示意圖：只有膝、踝與足部三個下肢點隨影片姿態移動，直接呈現左右髖屈曲／伸展、膝屈曲，以及踝背屈／蹠屈；站直中立位定義為 0°。
- 輸入身高後提供公分估計；未輸入時顯示身高百分比。
- 自動偵測影片實際呈現幀率（15–60 fps）並以相同頻率取樣；不支援偵測時回退至 30 fps。
- 步頻、踝路徑、質心與觸地事件時間軸可直接拖曳，並同步控制影片及其他圖表。
- 完整逐取樣 Raw CSV、JSON，以及含目前影像、圖表、事件與 Raw Data 的單檔 HTML 檢測報告。
- 支援系統分享面板；手機瀏覽器支援檔案分享時可直接選擇 LINE，否則提供網站連結分享及報告下載。
- 手機與平板橫向時採左側影片、右側數據雙欄配置；右側完整數據欄可獨立上下滑動。
- 觸地明細以暗藍／暗橘列底區分左右腳；上方提供各指標左右平均值 ± 樣本標準差、左／右比值與相對 100% 的不對稱差距。
- 儀表板由上而下優先顯示踝關節軌跡、質心垂直晃動、步頻及下肢關節角度；分析取樣與播放同步跟隨偵測到的來源影片 FPS（最高 120 FPS），不支援影片逐格回呼的瀏覽器以螢幕刷新循環備援。
- 頁尾移除 Method & Limits 展示區；所有數據後方提供兩欄三列下載／LINE 轉傳面板，分別處理檢測報告書、原始影片及 Raw CSV。
- 足部離地高度圖以較大的 Y 軸尺規與影片秒數 X 軸呈現；輸入身高後改用公分，並在觸地事件位置標示編號。
- 踝關節以脛骨軸相對「足跟到足尖」的足部軸計算有號角度，中立位為 0°，正值為背屈、負值拆分為蹠屈，保留逐取樣數值。
- 分析後自動產生規則式「發現／教練建議」勾選清單；教練可取消或補充內容，只有保留項目會寫入報告。
- 檢測報告改為可直接下載及透過系統分享面板轉傳的 PDF，包含影格、圖表、左右比較、觸地事件、踝關節角度、完整 Raw Data 與勾選建議。

## 隱私與限制

- 影片保留在瀏覽器，不會上傳到 Firebase。
- 第一次分析需連線下載 MediaPipe 姿態模型。
- 所有數值都是單鏡頭 2D 推估，適合訓練觀察與人工複核，不是醫療診斷或實驗室金標準。
- 公分數是以使用者身高校正的單鏡頭估計；Center of Mass 是軀幹代理點，不是依體節質量計算的全身質心。
- 跑步機單鏡頭影片無法可靠取得地面步距；踝部指標改以每個同側完整週期的軌跡長、垂直範圍與累計路徑呈現。累計路徑會受到影片長度與取樣率影響，不直接代表能量消耗或跑步經濟性。
- 跑步機影片無法從人體位移直接估算真實速度或步幅。
- 踝關節角度會受鞋面遮蔽、鏡頭透視與足部關鍵點品質影響；文獻範圍只作合理性提示，不會用來取代或強制校正量測值。

## 本機執行

```bash
npm test
npm run serve
```

開啟 `http://localhost:4173`。也可直接雙擊 `index.html`；已發布的 `app.bundle.js` 支援本機 `file://` 影片匯入。

## 方法來源與授權

本工具的足部高度正規化、由向下穿越閾值辨識觸地，以及使用同腳 stride interval 計算 cadence 的概念，參考 Jeremy Park 的 Apache-2.0 專案 [`vision-demos/running`](https://github.com/jeremyipark/vision-demos/tree/main/running)。本專案以瀏覽器端 MediaPipe Pose Landmarker 重新實作，並未複製其 VLM Run API 或 Python 執行架構。
